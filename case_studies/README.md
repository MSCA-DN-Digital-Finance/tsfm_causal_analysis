# Case Studies

This directory contains the case study datasets and exploratory data analysis notebooks.

The first case study is based on the "UNISOLAR Power Generation Dataset"[1] and the "SWaT Dataset: Secure Water Treatment System".

You need to download and place the case study datasets in their respective folders before executing any code.

Place [Solar_Energy_Generation.csv](https://www.kaggle.com/datasets/cdaclab/unisolar?select=Solar_Energy_Generation.csv) in the `unisolar` folder.

Place [normal.csv](https://www.kaggle.com/datasets/vishala28/swat-dataset-secure-water-treatment-system?select=normal.csv) in the `swat` folder.



[1] S. Wimalaratne, D. Haputhanthri, S. Kahawala, G. Gamage, D. Alahakoon and A. Jennings, "UNISOLAR: An Open Dataset of Photovoltaic Solar Energy Generation in a Large Multi-Campus University Setting," 2022 15th International Conference on Human System Interaction (HSI), 2022, pp. 1-5, doi: 10.1109/HSI55341.2022.9869474.
